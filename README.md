### 🚀 Featured Project

#### 🎯 [CONECTA UNSA — Intelligent Job Platform](https://hackathon-unsa-desafio1.vercel.app)

An AI-driven employment platform that connects university graduates with relevant, salary-transparent job opportunities.

- 🤖 **AI extraction pipeline** with **Gemini 2.0 Flash** + **Groq/Llama 3.1** fallback — raw email text → structured listings in one click.
- 🧠 **Semantic recommendations** using `text-embedding-004` + **pgvector** cosine similarity (personalized Top-3 per user).
- 🔔 Keyword-based real-time alerts, in-app notifications & a salary-transparency nudge for employers.
- 💸 Runs entirely on **free tiers (~$0 cost)** — built for a public institution.

`Next.js 16` · `React 19` · `TypeScript` · `Tailwind CSS` · `Supabase` · `pgvector` · `Gemini` · `Groq` · `Vercel`
